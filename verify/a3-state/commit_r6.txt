note right of S : busy state; note left of T2 : t2 note`: the card for
`note right of S` lands a layer on, past S's own fan, with T2 below it.
The facing-side elbow (f50fe3e) left S's bottom and rounded into the
card, crossing the S -> T2 transition, which runs between them. The
elbow guard only looked for boxes near the elbow, not strokes.

note_elbow now also takes every other edge's chord (the segment
between its ends' centres, edge_chords; none for a self-loop or an
invisible link) and keeps the ordinary link when either leg of the
elbow properly crosses one. The static scene and route / route_partial
pass the same chords in flow coordinates, so dragging gives the same
answer. Chords are only built when the graph has a note card, so
flowcharts and note-less state diagrams do no extra work.
