Flowmaid vs Mermaid

Sumber .mmd yang sama dirender dengan mermaid.js 12.2.0 dan flowmaid 0.32. Kesannya memang benar: flowmaid terlihat lebih jelek. Penyebabnya bukan warna atau font. Per elemen, flowmaid sering lebih rapi. Yang kalah adalah komposisi: bentuk edge, back-edge, kepala panah, dan layout cluster. Selain itu ada beberapa bug yang menghilangkan informasi.

Lima alasan terbesar

  1. Tiga gaya edge dalam satu gambarEdge antar-rank bersebelahan jadi cubic S, edge panjang jadi B-spline, dan hanya edge yang diperbaiki router yang orthogonal. Mermaid 12.2 (ELK) membuat semua edge orthogonal dengan sudut membulat. Terlihat di sekitar 14 diagram.
  2. Back-edge digambar sebagai satu lengkungan lebarHasilnya bentuk laso dan loop V yang menggantung. Panah masuk pada sudut sekitar 14° dan setengahnya tertutup node. Kanvas jadi membengkak. Terlihat di sekitar 11 diagram (scene.rs:3347-3370).
  3. Kepala panah tidak konsistenPada ==> kepalanya 2× ukuran normal (scene.rs:2494). Glyph-nya sempit dan stroke menyembul melewati ujung. Segmen terakhir tidak tegak lurus terhadap sisi node.
  4. Struktur layout salah pada diagram ber-cluster dan diagram padatSubgraph bersarang hilang dan direction di subgraph diabaikan. Node tanpa edge diparkir di rank 0. Akibatnya diagram LR berubah portrait, dan crossing-nya 1,6–4× lebih banyak dari mermaid.
  5. Informasi hilang atau artinya salahNote di state dan class, «interface», dan komentar ER tidak ikut dirender. Chip label ER menutupi lingkaran "zero", jadi o{ terbaca |{. Hierarki class terbalik.

Prototipe perbaikan

Prototipe ini dibuat saat verifikasi, di salinan repo dalam scratchpad. Repo aslinya tidak diubah. Gambar ini hanya bukti bahwa arah perbaikannya benar. Kodenya belum layak dirilis.

Roadmap

Urutannya ditentukan oleh dampak visual dikali jumlah diagram yang terdampak, lalu dibagi effort. Item yang ditulis "bersama" harus dirilis dalam satu PR, karena kalau dirilis sendiri justru memperburuk hasil.

Sprint 1 fondasi + kemenangan cepat

  1. Metrik kualitas baru + revisi gate lama. Beberapa gate di tests/quality.rs justru mengunci defect: MAX_ASPECT melindungi loop 230px di wide-labels. Perlu metrik baru: ujung di outline, wiggle menyamping, edge keluar frame sendiri, dan sudut masuk panah.
  2. Marker panah satu ukuran (userSpaceOnUse), bersama trim path di bawah kepala. Kepala ==> jadi sama dengan kepala normal, dan tidak ada lagi stroke yang menyembul.
  3. Bounding box kanvas dihitung dari ekstrem kurva, bukan titik kontrol. Margin jadi seimbang di 7 diagram.
  4. Fix parser subgraph bersarang dan proxy edge-ke-subgraph. Sudah diprototipe, 620 test lulus.
  5. Quick fix back-edge dan bug sumbu label LR. Lebar demo 383→321 dan tinggi wide-labels 413→201.

Sprint 2 polish + paket port

  1. Helper kontras di style.rs untuk memilih teks putih atau gelap per warna. Satu perubahan ini memperbaiki 8 tipe diagram yang gagal WCAG AA.
  2. Warna cluster per kedalaman, dengan stroke berkontras ≥3:1.
  3. Cylinder: label di tengah body, tutupnya diisi, dan stroke mengikuti style.
  4. Dukung classDef default. Ganti pola dotted dari 5 4 ke 2 3.
  5. Paket ruang label + port, dirilis bersama: gap rank untuk edge berlabel, port merata, dan panah mendarat di tengah sisi.
  6. Edge antar-rank bersebelahan jadi Z orthogonal dengan sudut membulat.

Sprint 3 paritas penuh

  1. Back-edge sebagai lane orthogonal yang diurus router, plus aturan agar edge tetap di dalam frame-nya sendiri.
  2. Semua edge flowchart orthogonal: chain dummy diubah jadi polyline, lalu nudge/spread memisahkan channel. Ini faktor visual terbesar.
  3. Untuk graf besar: greedy FAS dan network simplex, supaya bench-75 benar-benar mengalir ke kanan.
  4. Compound layout untuk direction di subgraph.

Yang jangan sampai hilang

Hal-hal berikut sudah lebih baik di flowmaid, jadi jangan dikorbankan demi meniru mermaid.

  • Chip label putih yang berpadding. Label mermaid berupa blok abu-abu dan sering ditembus garis.
  • Judul cluster tidak pernah tertabrak edge. Mermaid mencoret "Platform" dan "Event bus".
  • Diamond kompak untuk label pendek (102×65, sementara mermaid 171×171).
  • SVG portabel: pakai <text> tanpa foreignObject, ukurannya 5–10× lebih kecil, dan punya aria.
  • Menghormati <br/> dan tidak menghasilkan wrap yatim. Auto-wrap cukup untuk label tanpa break eksplisit.
  • Self-loop yang jelas. Self-loop di mermaid rusak di advanced dan stress.
  • Semantik dotted dan thick tetap terjaga. Mermaid mengubah 2 edge dotted jadi solid di dense-td.
  • <<choice>>/<<fork>> di state digambar benar. Mermaid 12.2 menggambarnya sebagai kotak.
  • Pie, journey, timeline, dan sankey sudah setara atau lebih baik.
  • Palet semantik per-shape. Tawarkan tema netral sebagai opsi, bukan pengganti.

Metode

Semua contoh di examples/*.mmd dan tests/fixtures/quality/*.mmd dirender, kecuali mode advance. Mermaid dijalankan di Chromium headless dengan konfigurasi default, flowmaid lewat CLI release build. Di class.mmd, deklarasi class A, B dipecah jadi dua baris, karena mermaid tidak menerima sintaks itu. Setiap diagram ditinjau satu agent. Agent kedua lalu mencoba membantah setiap temuan dan menelusuri akar masalahnya di src/. Satu audit terpisah membandingkan token gaya global. Nomor baris mengacu ke commit 5f318a0.
